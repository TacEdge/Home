# ADR 0001 — V0.1 architecture decisions

Status: **Accepted**, 2026-09-30.

## Context

The HOME architecture went through two review rounds (rev 1: initial architecture; rev 2: calendar provider interface, model routing, profiles, capture, channel-agnostic Kev, Context). Rev 3 settles the open decisions and adds the Insight concept.

## Decisions

| # | Decision |
|---|---|
| D1 | Google Calendar first, through the ICS adapter (Google's secret iCal address). `CalendarProvider` stays provider-neutral; other providers are added later without delaying V0.1. |
| D2 | Hosting: Vercel `syd1` + Neon Postgres, Sydney. |
| D3 | Claude API approved, sending the minimum necessary family context per request under the privacy rules. |
| D4 | Fast/deep model routing. Initial mapping `fast` = `claude-sonnet-5-5`, `deep` = `claude-opus-5-5`; model names are configuration only. Spend cap NZ$50/month; usage visible in Settings. |
| D5 | Every Kev change is a proposal requiring approval; the verbatim `capture` is the only exception. |
| D6 | Photos in V0.2. |
| D7 | This household only; no SaaS or multi-household preparation. |
| D8 | Two adult users; children are profiles. |
| D9 | Conversations retained 90 days, private per user. |
| D10 | Stack: TypeScript, Next.js, Postgres, Drizzle, Zod, Tailwind, Better Auth, Claude API. |
| D11 | `Pacific/Auckland`. Home location is private configuration/data, never repository source. |
| D12 | Week Ahead in V0.1, on demand. |
| D13 | Kev: warm, calm, concise, natural NZ English; perceptive, understated, occasionally playful; never nagging, corporate or over-enthusiastic; emoji extremely sparingly. |
| D14 | Exact user input is captured immediately and privately without approval; interpretation and organisation require approval. |
| D15 | Sensitive context: user-recorded only, never auto-included, never Kev-proposed. |
| D16 | Staleness periods (interest/preference 12 months, routine 6, intention 3, practical 12) are heuristics, not expiry or deletion rules. |
| D17 | Age from date of birth. No NZ school-year inference in V0.1. |
| D18 | No real family information in repository docs, fixtures, screenshots or automated tests. Real data exists only in the database and private configuration. |
| D19 | **Insight, not notification.** HOME surfaces insights when someone looks; no push notifications in V0.1. Insights are derived on read by deterministic detectors; Kev phrases and prioritises them; only dismissals persist. |

## Consequences

- Schema adds `insight_response`; everything else in rev 2 stands.
- The `stage` engine becomes `profile` (age + regular week only).
- The feature set for V0.1 is now **closed**. Further additions go to the roadmap, not V0.1.
- Next: M0 experience concepts for Today, Forward and Kev, approved before any code.
